🏆 Sistema de Inscripciones Online - Club Deportivo Juventud

Un sistema de registro web liviano, intuitivo y responsivo pensado para que socios y deportistas puedan inscribirse a actividades desde cualquier dispositivo (computadora o celular). 

Los datos ingresados se envían e integran directamente con una planilla de **Google Sheets** en tiempo real, funcionando como una base de datos sin costo de mantenimiento ni servidores complejos.

## 💡 ¿Cómo funciona?

1. El usuario completa sus datos (Nombre, DNI, Edad, Deporte, Categoría y Tutor responsable) desde la web o el celular.
2. Al confirmar, la aplicación hace un envío `POST` mediante la API de **Google Apps Script**.
3. La solicitud procesa la información y crea una fila nueva automáticamente en la planilla de Google Sheets.
4. La página cuenta además con un panel de administración protegido con clave para filtrar inscritos por deporte, ordenar por fecha o buscar por DNI durante la sesión.

---

# 🛠️ Tecnologías utilizadas

* **Frontend:** HTML5, CSS3 (CSS Variables, Flexbox, CSS Grid), JavaScript (Vanilla JS).
* **Backend / Base de Datos:** Google Apps Script (JavaScript) + Google Sheets API.
* **Diseño:** Responsive Design (Mobile First) con interfaz moderna basada en componentes.
* **Hosting:** GitHub Pages.

---

## 📌 Características principales

- 📱 **100% adaptable a celulares:** Funciona sin problemas desde WhatsApp o navegadores móviles.
- ⚡ **Sin backend dedicado:** Utiliza la infraestructura de Google para almacenar los datos a costo $0.
- 🔍 **Panel de Administración integrado:** Filtros por deporte, ordenamiento de datos e historial de inscripciones.
- 💬 **Integración con Redes:** Botón directo para contacto por WhatsApp con la presidencia del club.
